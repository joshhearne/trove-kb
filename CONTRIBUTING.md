# Contributing

All commits must be signed off under the Developer Certificate of Origin (https://developercert.org).
Use `git commit -s`. PRs without sign-off will not be merged.

Open pull requests against `dev`, not `main`: `main` only moves when `dev` is
released (see README → Branches and releases). A change people will notice adds
a file to `changes/` (see `changes/README.md`).

By contributing you agree your work is licensed under AGPL-3.0.
